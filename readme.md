Employee Management System
A full-stack Employee Management System built using React.js, Node.js,
Express.js, and MySQL. The application provides a simple interface to
add, view, search, update, and delete employee records.
Features
- Add new employees
- View all employee records
- Update employee details
- Delete employees with a confirmation prompt
- Search employees by Employee ID, name, email, or department
- Dashboard statistics:
  - Total employees
  - Total departments
  - Average salary
- Frontend form validation and backend input validation
- Error handling for invalid input, duplicate email addresses, and
  employees that do not exist
- RESTful API integration
- MySQL database integration
- Responsive user interface

Prerequisites
Install the following before running the project:
- Node.js and npm
- MySQL Server
- A code editor such as Visual Studio Code
Installation and Setup
1. Get the project
After cloning your GitHub repository, open a terminal in the project
directory:
git clone YOUR_GITHUB_REPOSITORY_URL
cd employee-management-system
Replace YOUR_GITHUB_REPOSITORY_URL with the actual repository URL.
2. Install backend dependencies
Run this command from the project root:
npm install
3. Create the MySQL database and table
Open MySQL Workbench or a MySQL terminal and execute:
CREATE DATABASE employee_management;

USE employee_management;

CREATE TABLE employees (
    employee_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    department VARCHAR(100) NOT NULL,
    salary DECIMAL(10,2) NOT NULL
);
The employee_id is generated automatically by MySQL. The primary key
ensures that each employee has a unique ID, and the unique constraint
prevents duplicate email addresses.
4. Configure environment variables
Create a file named .env in the project root. Use .env.example as a
reference and add your own local MySQL credentials:
DB_HOST=localhost
DB_USER=your_mysql_user
DB_PASSWORD=your_mysql_password
DB_NAME=employee_management
DB_PORT=3306
PORT=5000
Update DB_USER and DB_PASSWORD to match your MySQL setup.

Security note: Do not commit your actual .env file or database
password to GitHub. The .env file should be listed in .gitignore.
Share only placeholder values in .env.example.
5. Start the backend server
From the project root, run:
node server.js
The backend API runs at:
http://localhost:5000
The root endpoint can be opened at http://localhost:5000/ to check
that the API server is running.

Keep this terminal open while using the application.
6. Install frontend dependencies
Open a second terminal and run:
cd frontend
npm install
7. Start the frontend
From the frontend directory, run:
npm run dev
Vite will show the local development URL. By default, it is:
http://localhost:5173
Open that URL in your browser. Make sure the backend server and MySQL
server are running.
API Endpoints
The backend exposes the following employee endpoints:

  Method   Endpoint               Description
  GET      /api/employees       Retrieve all employees
POST     /api/employees       Add a new employee
PUT      /api/employees/:id   Update an employee
DELETE   /api/employees/:id   Delete an employee
Employee fields
  Field           Description
  employee_id   Auto-generated unique employee ID
name          Employee name
email         Employee email address; must be unique
department    Employee department
salary        Employee salary; must be a non-negative number
Validation and Error Handling
The application includes validation and error handling for:
- Missing required fields
- Invalid email format
- Negative or invalid salary values
- Duplicate email addresses
- Invalid employee IDs
- Employee records that cannot be found
- Database errors
Employee IDs are generated by MySQL using AUTO_INCREMENT, and
duplicate IDs are prevented by the primary key constraint.
Usage
1. Start MySQL and the backend server.
2. Start the frontend development server.
3. Open the frontend URL in your browser.
4. Use the interface to add, view, search, update, and delete employee
   records.
